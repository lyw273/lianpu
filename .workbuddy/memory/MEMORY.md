# 掌上国粹（脸谱大师）项目记忆

## 项目概况
- **文件**：`face-catch-game.html`（同步为 `index.html` 推送到GitHub）
- **仓库**：https://github.com/lyw273/lianpu.git
- **Pages链接**：https://lyw273.github.io/lianpu/
- **技术栈**：纯单文件HTML，零外部CDN依赖，原生JS肤色检测+Canvas渲染

## 核心功能（截至2026-06-23 第九轮）
- 8个Q版卡通小人SVG角色（关羽/孙悟空/婵娟/张飞/包拯/窦尔敦/典韦/曹操）
- 白色卡通手套指示器（张开/握拳两种状态，握拳时scale缩小）
- 30秒限时积分制游戏（不同角色120~200分不等）
- 摄像头前置+背景虚化（视频opacity 0.88，半透明云层叠加，暗角遮罩）
- 精准手势识别：运动检测+面部排除+形状过滤+严格HSV阈值
- 双手多点手势追踪（独立detCanvas检测画布）
- 鼠标/触摸操控降级模式
- 摄像头权限友好提示UI
- 结算评语系统（6档评语）

## 关键技术决策
- 独立detCanvas(160x120)避免污染游戏画布
- handPoints[]数组(MAX_HANDS=2)支持双手追踪
- 贪心最近距离blob→slot匹配算法
- 运动检测（prevFrameData帧间对比）+面部排除（上方38%中心60%区域）+形状过滤（长宽比0.2~3.0）
- HSV手部肤色检测(H 5-55, S 0.12-0.85, V 0.20-0.95) + 形态学清理(8方向膨胀+腐蚀)
- 肤色+运动联合置信度（高置信度=运动区域内肤色，低置信度=静止肤色）
- 面积变化法握拳检测
