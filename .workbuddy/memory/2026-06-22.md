## 重构：彻底去除MediaPipe依赖，改为纯原生JS

- **原因**：MediaPipe CDN加载不稳定，用户无法使用手势
- **方案**：完全原生JS肤色检测（HSV色域范围）
- **手势识别**：肤色blob连通区域分析 → BFS找最大blob(脸)和第二大blob(手)
- **握拳检测**：面积变化法
- **零外部依赖**：不需要任何CDN，纯原生JS + Canvas + getUserMedia

## 第七轮（2026-06-23）：重写双手多点追踪

- **问题**：只有1个识别点；识别点卡在角落；检测画布污染游戏画布

  1. `ctx.drawImage(video,...)` 把视频内容画到游戏画布上，污染了游戏渲染
  2. 只取 blobs[1] 作为手，最多1个手点
  3. 坐标映射偏差（低分辨率sample + 没有正确处理镜像）
- **重写内容**：
  - 新增独立 `detCanvas`（160×120）专门用于皮肤检测，不污染游戏canvas
  - 新增 `handPoints[]` 数组（MAX_HANDS=2），每个手点独立追踪：平滑位置、面积历史、握拳状态、冷却帧
  - 新增 `makeHandPoint()` 工厂函数
  - 重写 `detectSkinBlobs()`：BFS改为数组队列（无shift开销），blob匹配用贪心最近距离分配到slot，blob分类逻辑（1个/多个blob时分别处理），镜像坐标翻转修正
  - 重写 `detectGrabGesture()`：每个handPoint独立判断握拳
  - 重写 `tryGrab()`：遍历所有handPoints，每个手点有独立冷却(20帧)
  - 新增动态创建多个手指示符（黄色=第一只手，绿色=第二只手）
  - 多点触摸支持：touchPoints数组对应多个hand slot
  - _startGameInner重置handPoints[]和grabCooldownGlobal
- **已推送**：commit a922ee0 → github.com:lyw273/lianpu.git main

### 改动内容

  - 新增`#blur-layer`层（backdrop-filter: blur(3px))对视频施加轻微虚化
  - 新增`#vignette`暗角遮罩层（径向渐变，中心透明→边缘暗色）
  - 无摄像头模式时隐藏video/blur-layer/vignette，显示纯渐变背景
- **背景虚化**：
  - 游戏场景（天空渐变、云层、草地）改为半透明绘制
  - `drawCloudOverlay()`用rgba低透明度渐变代替全opaque渐变
  - 云层opacity从0.6降到0.45
  - 草地opacity从0.35降到0.22
  - 暗角虚化效果（径向渐变遮罩）
- **精准手势识别**（三大改进）：
  1. **运动检测（Motion Detection）**：
     - 新增`prevFrameData`存储前一帧像素数据
     - 对比当前帧与前一帧，计算像素差异（dr+dg+db > 45 = 运动）
     - `motionMask[]`标记运动像素
     - 肤色+运动联合判断：运动区域内的肤色像素标记为高置信度(2)，非运动区域为低置信度(1)
     - 低置信度像素在面部排除区域被清除
  2. **面部排除（Face Exclusion）**：
     - 排除画面上方38%区域内、水平中心60%范围内的低置信度肤色像素
     - 大面积blob(>120px)在上方30%区域自动排除
     - 大面积blob(>300px)在中间区域(上方45%)且水平居中范围内排除
  3. **形状过滤（Shape Filtering）**：
     - 更严格的HSV范围：H 5-55（从0-65缩窄）、S 0.12-0.85（从0.07-0.92缩窄）
     - 最低色差从10提高到12（排除接近灰色像素）
     - blob长宽比过滤：aspectRatio在0.2~3.0之间（排除过于细长的手臂或过方区域）
     - 运动置信度过滤：面积>150的blob中运动像素比例需>15%
     - blob面积上限从2000降到800（排除面部+身体大面积区域）
- **形态学改进**：膨胀改为8方向（含对角线），腐蚀也更严格
- **平滑系数**：从0.4改为0.45，手势响应更灵敏
- **丢失帧阈值**：从8帧降到6帧，更快释放丢失的手点
- **UI升级**：所有UI栏增加backdrop-filter: blur()毛玻璃效果
